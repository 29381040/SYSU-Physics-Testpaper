这是为了收集记录中山大学物理学院各考试而创建的。任何人都可以在文件夹中上传有价值的资料。

本文件夹的核心目的是收集专业课程资料，例如数学基础课程(高数、线代、概统)、五小力学课程、四大力学课程的考试真题，其余无关的必修课课程真题不是主要任务。

各位在添加时请务必按照文件夹标题进行添加，没有找到标题但是是必修课考试卷的可以上传到“其他资料”部分。

管理员也会定期进行维护和清理。

上传文件的要求：

  1.文件格式：仅限pdf、word文件，如果是拍照图片等形式也要转换成这两种形式上传。LaTeX模版可以在主文件夹中找到。为统一大家的格式，请大家尽量使用此模版进行排版上传。
  
  2.文件名称：考试年份-科目-考试名称(-A、B卷)，如“2025-力学-小测1”、“2026-热学-期中”、“2026-量子力学-期末-A”，年份以考试时间为准，不要用年级计算。例如2025级的热学考试是在2026年考的，因此要写2026-热学。
