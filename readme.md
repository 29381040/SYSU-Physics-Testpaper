这是为了收集记录中山大学物理学院各考试而创建的。任何人都可以在文件夹中上传有价值的资料。

本文件夹的核心目的是收集专业课程资料，例如数学基础课程(高数、线代、概统)、五小力学课程、四大力学课程的考试真题，其余无关的必修课课程真题不是主要任务。

各位在添加时请务必按照文件夹标题进行添加，没有找到标题但是是必修课考试卷的可以上传到“其他资料”部分。

管理员也会定期进行维护和清理。

上传文件的要求：

  1.文件格式：仅限pdf、word、png、jpg文件，后两种图片格式仅限只有一张图的情况，多张图请合并pdf上传。LaTeX模版可以在主文件夹中找到。为统一大家的格式，请大家尽量使用此模版进行排版上传。
  
  2.文件名称：考试年份-科目-考试名称(-A、B卷)，如“2025-力学-小测1”、“2025-热学-期中”、“2024-量子力学-期末-A”，年份由考试当年的学年起点决定，不要用考试时间计算。例如2024级的量子力学是在2025学年下学期的2026年6月考的，就要写2025-量子力学。如有答案请再标明，如“2025-力学-小测1-答案”。如果年份未知，可以写未知年份1、未知年份2等，后面的序号根据目前试题库顺序一次增加。免修考试是前一个学期的。例如2025级光学正常修读在2026学年第一学期，但是免修考试在2025学年第二学期举行，因此试卷标注还是2025-光学-免修。

试题库维护的要求：

  1.如果发现题目存在答案不全情况，可以自己将该文件的文件名从“xxx-答案”改为“xxx-部分答案”。

  2.不允许擅自删除试卷。
